# Smart-Savings

Aplicação web com calculadoras de investimento, autenticação de utilizadores e base de dados Firebase. Projeto desenvolvido em grupo.

## Capturas de ecrã

![Página do Smart-Savings](assets/images/README/001.png)
![Interface do Smart-Savings](assets/images/README/002.png)

## Funcionalidades
- Calculadoras para simular a evolução de investimentos
- Comparação de cenários de investimento
- Conteúdos educativos sobre finanças pessoais
- Autenticação de utilizadores e ligação ao Firebase

## Tecnologias
JavaScript · HTML · CSS/SCSS · Firebase · Chart.js
